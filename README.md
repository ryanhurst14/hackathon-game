"To Kill a Labubu" was the 2025 UQCS Hackathon Best Game winner! Enjoy this small project where you, a Lababu, must help the performative males combat the sigma males. 
Defeat the 48 Laws of Power, and collect performative powerups like jorts and wired headphones to ultimately defeat the ominous final boss!

This was coded using the open source game engine Godot. To run the game, visit the actions tab, then the latest pages build and deployment. Click on the deploy link and it will run :)
